# Changelog

## 1.0.0 — initial release

- One-tap isometric stacking with trim, perfect snap, combo chimes and block regrow.
- Neon synthwave scenery: retro sun, perspective grid, bokeh, stars, glowing grid floor.
- Game-over camera zoom-out, falling slices, sparks, ripples, milestone banners.
- Title screen with a live bot-built tower; `?demo=1` attract mode.
- Pause (Esc/P, auto-pause on hidden tab), sound toggle (M), best score, share button.
- Monetization / analytics hooks, fully translatable texts, one commented config file.
