# Changelog

## 1.0.0 — initial release

- 12 handcrafted levels in a plain-text format; victory and loop mode.
- Plated, steel, explosive (chain reaction) and power-up bricks.
- 8 power-ups: Multi-ball, Wide, Lasers, Slow, Fireball, Catch, +1 Life, Shrink.
- Sub-stepped ball physics, paddle angle control, minimum-angle rule.
- Combo multiplier, clear bonus tally, last-brick slow motion.
- Level select with saved progress, best score, share button.
- Desktop side panels, taller field on tall phones, title bot, `?demo=1` mode.
- Monetization / analytics hooks, translatable texts, optional image skins.
