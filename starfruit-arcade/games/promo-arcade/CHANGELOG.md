# Changelog

## 1.0.0 — initial release

- Three branded mini-games: Catch Rush, Memory Match (3D flip cards) and Spin & Win (prize wheel).
- "Play & Win" hub page with animated game previews and a rewards list.
- One-file rebrand in `brand.config.js`: logo, colours with automatic text contrast, fonts,
  products, game names, rewards, wheel prizes, call-to-action, legal text, all shared texts.
- 22 built-in flat SVG icons; product pictures from icons, image files or emoji.
- Coupon ticket with Copy button; score tiers, star tiers and weighted wheel odds.
- Optional lead capture (name / email / phone + consent) posted to any webhook.
- Spins-per-day limit, share button, analytics / CRM hooks.
- Confetti, particles, combos, LED chase lights, ticking flapper, synthesized sound.
- Pause, auto-pause on hidden tab, keyboard play, reduced-motion support, `?demo=1` mode.
