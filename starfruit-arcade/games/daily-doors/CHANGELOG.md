# Changelog

## 1.0.0 — initial release

- Advent / countdown calendar with any start date and 1–60 doors that unlock at local midnight.
- Scratch-off reveal (metallic foil, sparkles, dust, sound) or tap-to-open mode.
- Shuffled gift-wrap doors in brand colours, glowing "Today" door, live next-door countdown.
- Treat ticket with coupon code and Copy button, or message doors (tips, recipes, thank-yous).
- Opened doors remembered per campaign; missed doors optional.
- Scratch & Win page with weighted prizes and a cards-per-day limit.
- Optional lead capture to any webhook; hooks for analytics and CRM.
- Snow, stars or confetti backgrounds; `?date=` preview and `?demo=1` attract mode.
- One-file setup in `config.js`, translatable texts, keyboard support, reduced-motion support.
