# Changelog

## 1.0.0 — initial release

- Personality / product-finder quizzes with weighted answer points and a "your mix" breakdown.
- Trivia quizzes with right/wrong feedback, explanations, optional timer and result tiers.
- Results with product recommendation, coupon ticket, per-result call-to-action.
- Shareable 1080 × 1350 result image (Web Share or PNG download).
- Optional lead capture to any webhook, including the quiz result.
- Picture or text answers, shuffling, Back button, progress bar, card transitions.
- Keyboard play, reduced-motion support, `?demo=1` attract mode, analytics hooks.
- One-file setup in `config.js`, translatable texts, trivia example page.
