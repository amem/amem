The math

Agencies typically charge local businesses a setup fee plus a few hundred dollars a month for an AI website assistant. One client covers the cost of ClientBot Studio, and every client after that is margin. Your running costs are your own hosting (one small server for all clients, typically $6–12/month) and AI usage paid directly to your provider. The dashboard shows the estimated AI cost of every bot.

Requirements

  • A server or hosting that runs Node.js 20+ or Docker (a $6/month VPS is plenty)
  • An Anthropic API key (recommended) or any OpenAI-compatible API key. Demo mode works without one.
  • Optional: an SMTP email provider for lead alerts

FAQ

Do I need to know how to code?
Not to use it. You install it once with copy-paste commands or Docker, then everything happens in the dashboard. If you want to customize the code, it's clean TypeScript with a developer guide.

Are there monthly fees?
No platform fees. You pay only your own hosting and AI usage, directly to Anthropic or OpenAI.

Can I use it for unlimited clients?
Yes. Host bots for as many clients as you like and charge them anything. You can't resell or share the source code itself.

Will it work on my clients' websites?
On any site that allows a custom script: WordPress, Webflow, Wix (premium), Squarespace (Business), Shopify, GoHighLevel and custom sites. There's also a hosted chat link for everything else.

Does it answer in other languages?
Yes. It replies in the visitor's language by default, and all widget texts are editable.

Do I get updates?
Yes, 12 months of updates are included.
