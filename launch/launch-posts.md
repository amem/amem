> **Title:** What I learned building a self-hosted AI chatbot platform for agencies (and the stack I used)
>
> I've been building AI website assistants for local businesses and kept paying monthly for white-label platforms, so I built my own: multi-client dashboard, knowledge base (website import + PDFs + Q&A), lead capture, client portal and white-labeling.
>
> A few things that mattered more than I expected:
> - **Small knowledge bases shouldn't use RAG.** For most local businesses (under ~40k tokens), putting the whole knowledge base in a cached system prompt beats vector search on accuracy, and prompt caching keeps it cheap. Search only kicks in for big sites.
> - **Lead capture should be triggered by intent**, not a timer. The model decides when someone wants a quote or booking and asks for details then.
> - **Per-client message caps** are what make it sellable as tiered plans.
> - **SQLite is enough.** One server handles lots of client bots.
>
